# Project: Puwadon's Engineering Journey

## 1. Project Overview

Develop a modern personal website that serves as a digital representation of Puwadon Hamvivil's professional journey, engineering experiences, technology knowledge, projects, and continuous learning path.

This platform should not be a traditional resume website.

Instead, it should allow visitors to explore career milestones, engineering experiences, lessons learned, projects, and knowledge sharing through an interactive and engaging experience.

The website should reflect the evolution of an engineer, from early web development experiences to enterprise software development, insurance domain expertise, and modern AI and cloud technologies.

---

## 2. Project Objectives

The platform should help visitors:

- Understand Puwadon's professional background.
- Explore career and technology journey.
- View projects and achievements.
- Learn from real-world lessons and experiences.
- Follow current learning activities and interests.
- Engage through reactions and comments.

The platform should also serve as a personal knowledge repository that can be extended with AI-based search and chatbot capabilities in future phases.

## 4. Main Features

### 4.1 Home Page

The home page should provide a summary of:

- Personal introduction
- Professional summary
- Years of experience
- Core technology expertise
- Current learning topics
- Featured projects
- Latest articles
- Recent journey updates

---

### 4.2 Engineering Journey

Provide a timeline-based experience showing significant milestones.

Examples:

- Started learning programming
- Built first website (Puwadon.com)
- Started professional software development
- Worked with Oracle technologies
- Entered insurance domain
- Started AI and cloud journey
- Built SDAT (Software Development Agent Team)

Each journey entry should contain:

- Title
- Date or year
- Story
- Technologies involved
- Key challenges
- Lessons learned
- Reflection

Reflection section should include:

- What Happened
- What I Learned
- What I Would Do Differently Today

---

Each project should contain:

- Project Name
- Overview

- Lessons Learned
- Screenshots or Media
- Project Status
